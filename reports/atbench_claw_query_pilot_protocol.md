# 跨工具取证 pilot 协议

本轮比较的单位是一条发送调用，一读指访问一个逻辑证据源一次。对照和规划器都按全部调用计费，失败查询也计一次。选择用四种发送工具代表两个发布物。结论的外推范围是这四种工具。训练和留出按原始轨迹分组，一个案例重放多次仍属于同一条原始轨迹。

- **主问题**为“一次已发生的投递是否超出当次授权”。公开日志检查各证据的来源、绑定方式与可核实范围。有独立真值才能报告正确判定覆盖率。
- **日志上的替代问题**是三个可读取来源是否共同出现同一收件人字面标识。以完整读取为参考，分别测试按工具选择的最佳固定次序和可以依据第一次读取改变第二步的策略；两者均可提前停止。它直接衡量这些真实文本上的字段读取收益，结论限定在字面标识上。
- **受控终态复放**仅采用可解析的单一主目标，保留工具及绑定类型。为每次调用独立枚举三种授权与三种收件状态，另做证据不可用的平衡敏感性分析。成本单位均为一次接口读取。带绑定 ID 的记录使用按操作 ID 直接读本地投递登记的适配器；仅相邻绑定的记录另需查询本地请求编号索引。后端能力、状态和缺失比例均为实验设定，公开轨迹不提供它们的实际分布。
- 两侧共享初始事实、预算、取证接口、已判定/无法判定提前停止和键依赖。对照同时覆盖开发数据选出的固定次序和每种工具/公开接口条件下穷举整个次序集合的最优参考。覆盖率定义为正确且确定的数量除以全部样本数，另报错误、弃权、总读数和配对差。多预算结果仅在正确覆盖相同时比较成本。
- **判断标准**：继续把省查询作为主贡献，需要在实际日志上超过强固定规则，并能在有独立终态的任务中复现。将平均每次调用至少少读 0.10 次作为本次选题的实用门槛，同时看按轨迹配对的区间和两个发布物的方向。一种受控接口下的收益或证据不足均不足以单独支持该主张。
